## 2. 변경 배경 및 목표
- **변경 전 상태:** Capture Mode는 `start_openlog_session`으로만 읽혔고, 세션 중 MCP로 바꿀 수 없었다. Tasks 목록 기본 필터는 `all`이라 DONE이 함께 보였고, 대시보드 Tasks 위젯·status legend에도 done이 노출됐다.
- **문제/필요성:** 사용자가 세션에서 Capture Mode 변경을 승인하면 바로 반영할 수 있어야 한다. DONE Task가 기본 화면에 쌓이면 지금 할 일이 묻힌다.
- **이번 PR의 목표:** Capture Mode MCP 조회·승인 후 수정 툴을 추가하고, Tasks UI 기본 뷰를 Active(todo+doing) 중심으로 바꾼다.

## 3. 주요 구현 내용 및 동작 방식

### A. Capture Mode MCP 조회·승인 후 수정
- **관련 위치/대상:** `packages/openlog-cli/src/mcp-workspace-tools.ts`, `packages/openlog-cli/src/mcp-server.ts`
- **변경 전 상황:** Capture Mode 변경은 웹 UI 또는 `openlog init`만 가능했다.
- **변경한 내용:**
  - `get_workspace_project` (`read`) → `GET /workspace-projects/{projectId}`
  - `update_workspace_project_capture_mode` (`write`) → preview 후 `confirm: true`일 때 `PATCH` (기존 displayName/repository 유지)
  - MCP instructions·README·mcpGuideContent 갱신
- **변경 후 동작:** 에이전트가 preview로 현재/다음 Capture Mode를 보여 주고, 사용자 승인 후 적용한다. 적용 후 `get_workspace_project` 또는 `start_openlog_session`으로 다시 읽어야 세션 컨텍스트가 갱신된다.
- **바뀌는 데이터/상태:** workspace project `captureMode`
- **영향 범위:** OpenLog CLI MCP (`safe-write` 이상). Backend API 변경 없음.

### B. Tasks Active 기본 필터 · 대시보드에서 done 숨김
- **관련 위치/대상:** `TasksListView.tsx`, `WorkspaceDashboardView.tsx`, `data.ts`
- **변경 전 상황:** `/tasks` 기본 필터 `all`, 대시보드 Tasks에 done 포함, legend에 done 표시.
- **변경한 내용:**
  - `TaskListFilter`에 `active` 추가, 기본 탭 Active (todo+doing)
  - 탭 순서: Active → Doing → Todo → Done → All
  - 대시보드 Tasks 목록·explore 위젯에서 done 제외
  - status legend에서 done 제거
- **변경 후 동작:** 기본 화면은 열린 작업만 보이고, Done/All 탭으로 히스토리에 접근한다.
- **영향 범위:** 워크스페이스 대시보드 Tasks, `/tasks` 목록 UI
