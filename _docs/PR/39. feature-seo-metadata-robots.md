## 2. 변경 배경 및 목표
- **변경 전 상태:** 최상위 레이아웃은 기본 제목과 설명만 제공했고 canonical, Open Graph, sitemap, robots 정책이 없었습니다. 공개 프로필과 게시글도 페이지별 검색 메타데이터를 제공하지 않았습니다.
- **문제/필요성:** 검색 엔진과 링크 미리보기가 공개 콘텐츠를 정확히 식별하기 어렵고, 인증·작성·설정 화면과 Preview 배포가 크롤링될 수 있었습니다.
- **이번 PR의 목표:** 공개 페이지에는 일관된 canonical과 공유 메타데이터를 제공하고, 비공개 경로와 Preview 환경에는 robots 정책과 응답 헤더를 함께 적용합니다.

---

## 3. 주요 구현 내용 및 동작 방식

### A. 전역 및 공개 페이지 SEO 메타데이터
- **관련 위치/대상:** `frontend/app/layout.tsx`, 공개 프로필·게시글 page, `frontend/src/04_shared/config/site.ts`, `frontend/app/opengraph-image.tsx`
- **변경 전 상황:** 사이트 공통 title과 description만 존재했고 공개 콘텐츠별 canonical, Open Graph, Twitter metadata가 없었습니다.
- **변경한 내용:** 사이트 이름·설명·기준 URL을 공통 설정으로 분리하고 전역 metadata와 1200×630 Open Graph 이미지를 추가했습니다. 공개 프로필과 게시글은 API 응답을 사용해 title, description, canonical, author, topic metadata를 생성합니다.
- **변경 후 동작:** 루트와 공개 콘텐츠가 고유한 검색 결과 정보와 링크 미리보기를 제공하며, 존재하지 않는 프로필과 게시글은 `noindex` 처리됩니다.
- **구현 흐름:**
  1. `NEXT_PUBLIC_SITE_URL` 또는 기본 운영 주소 `https://openlog.kr`로 metadata base를 결정합니다.
  2. 공개 페이지의 사용자·게시글 정보를 조회해 canonical과 소셜 metadata를 구성합니다.
- **바뀌는 데이터/상태:** HTML head의 title, meta, canonical, Open Graph, Twitter 태그
- **영향 범위:** 루트 페이지, 공개 프로필, 공개 게시글, 외부 링크 미리보기

### B. robots, sitemap 및 비공개 경로 방어
- **관련 위치/대상:** `frontend/app/robots.ts`, `frontend/app/sitemap.ts`, `frontend/next.config.ts`
- **변경 전 상황:** 크롤러 허용 범위가 정의되지 않았고 인증·워크스페이스·작성 화면과 Vercel Preview 배포를 검색 결과에서 제외하는 응답 정책이 없었습니다.
- **변경한 내용:** App Router metadata route로 `robots.txt`와 `sitemap.xml`을 생성했습니다. 비공개 경로에는 `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet`을 추가하고 Vercel Preview에서는 모든 경로를 차단합니다.
- **변경 후 동작:** 운영 환경은 공개 경로를 허용하면서 비공개 경로를 robots와 HTTP 헤더로 제외합니다. sitemap은 사이트 루트와 조회 가능한 최근 공개 게시글·작성자 경로를 반환하며 API 조회 실패 시에도 루트 URL을 유지합니다.
- **구현 흐름:**
  1. 배포 환경에 따라 robots 허용·차단 규칙을 생성합니다.
  2. Next.js headers 설정이 비공개 페이지와 Preview 응답에 `X-Robots-Tag`를 추가합니다.
- **바뀌는 데이터/상태:** `/robots.txt`, `/sitemap.xml`, 비공개 경로 HTTP 응답 헤더
- **영향 범위:** 검색 엔진 크롤링, Vercel Preview, 인증·작성·설정·워크스페이스 관련 경로

## 6. 리뷰어 참고 사항 (선택)
- **리뷰할 때 봐야 할 점:** `robots.txt`와 `X-Robots-Tag`는 정상 크롤러를 위한 검색 정책이며 인증 경계를 대체하지 않습니다. 운영 canonical 기본값은 `https://openlog.kr`이고 환경별 변경이 필요하면 `NEXT_PUBLIC_SITE_URL`을 사용합니다.
- **영향 범위:** 공개 검색 노출, 비공개 페이지 색인 정책, Vercel Preview 크롤링
