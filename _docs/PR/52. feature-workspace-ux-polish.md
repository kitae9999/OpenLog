## 2. 변경 배경 및 목표
- **변경 전 상태:** Task 상세의 Started/Updated는 linked log meta만 사용했고, `mapTask`는 `createdAt`/`updatedAt`을 버렸다. Logs 서브내비에는 NOTE 탭이 없었다. 대시보드 Todos는 `plannedFor=오늘`만 조회했다. Footer의 Terms/Privacy/Status는 페이지 없는 링크로 이동했다.
- **문제/필요성:** log가 없는 Task는 날짜가 비어 보였고, Planner가 숨겨진 뒤 날짜가 바뀌면 미완료 Todo가 대시보드에서 사라졌다. NOTE log는 생성 가능하지만 목록에서 필터할 수 없었다.
- **이번 PR의 목표:** Task 활동 시각을 올바르게 표시하고, Notes 탭·Todos 전체 조회·Legal/Status 이동 차단을 한 번에 반영한다.

## 3. 주요 구현 내용 및 동작 방식

### A. Task Started / Updated
- **관련 위치/대상:** `resolveTaskActivityMeta`, `mapTask`, Task detail/list, working brief, `WorkspaceTask.touch()`, `WorkspaceLogService`
- **변경 전 상황:** Started/Updated가 log meta에만 의존. log 생성 시 task `updatedAt` 미갱신.
- **변경한 내용:** Started=`createdAt`, Updated=`max(task.updatedAt, linked log.createdAt)`. log create/update 시 task touch.
- **변경 후 동작:** log가 없어도 생성·수정 시각이 보인다. log를 붙이면 Updated와 정렬이 갱신된다.
- **영향 범위:** Task 상세/목록, 대시보드 brief, task 목록 정렬에 쓰는 `updatedAt`

### B. Logs Notes 탭
- **관련 위치/대상:** `logsSubnavItems`, `/logs/notes`, `mapLogLabel`
- **변경 전 상황:** NOTE kind는 생성 UI에만 있고 목록 필터/라벨이 없음(`Log`로 표기).
- **변경한 내용:** Notes 서브내비·라우트 추가, NOTE → `Note` 라벨.
- **변경 후 동작:** `/logs/notes`에서 NOTE만 볼 수 있다.
- **영향 범위:** Logs 목록, 사이드바 Logs 그룹

### C. Todos 날짜 무관 전체 조회
- **관련 위치/대상:** `GET /workspaces/{id}/todos` (파라미터 없음), 대시보드 fetch, MCP `list_workspace_todos`
- **변경 전 상황:** 대시보드는 오늘 날짜 Todo만 로드.
- **변경한 내용:** 날짜 파라미터 생략 시 전체 목록(미완료 우선). MCP도 동일.
- **변경 후 동작:** 과거 `plannedFor`의 미완료 Todo가 대시보드에 남는다. 생성 시 `plannedFor`는 계약상 유지.
- **영향 범위:** 대시보드 Todos, Todo API, openlog-cli MCP

### D. Terms / Privacy / Status 이동 차단
- **관련 위치/대상:** Footer, `/terms` `/privacy` `/status`
- **변경 전 상황:** Footer 링크가 빈 페이지로 이동(또는 404).
- **변경한 내용:** Footer는 비클릭 라벨, 직접 URL은 `/`로 redirect.
- **변경 후 동작:** Legal/Status 페이지 준비 전까지 이동 불가.
- **영향 범위:** 공통 Footer, 해당 라우트

## 5. 테스트 및 검증 방법
- **검증 환경:** 로컬 `pnpm dev` + 로컬/연동 API
- **검증한 시나리오:**
  1. log 없는 Task 상세에서 Started/Updated가 날짜로 표시되는지
  2. `/logs/notes` 필터와 Note 라벨
  3. 어제 `plannedFor` 미완료 Todo가 대시보드에 보이는지 (백엔드 재시작 후)
  4. Footer Terms/Privacy/Status 클릭 불가, `/terms` 접근 시 홈 redirect
- **확인한 결과:** 코드 경로상 위 동작으로 연결됨. TodoService `getAllTodos` 단위 테스트 추가.
- **확인하지 못한 부분:** 운영 API 배포 전 prod 대시보드 전체 Todo 조회는 로컬 백엔드 기준으로만 확인 가능
