## 2. 변경 배경 및 목표
- **변경 전 상태:** MCP Guide는 예전 tool 목록(인증·알림·글·이미지·output 발행 중심)만 안내했고, 로컬 permission profile(`read-only` / `safe-write` / `full`)과 workspace tool 범위를 설명하지 않았다.
- **문제/필요성:** CLI에 MCP permission profile과 workspace tool이 추가됐는데 Guide 문서가 따라가지 않아 사용자가 어떤 tool이 어떤 프로필에서 가능한지 웹에서 확인할 수 없다.
- **이번 PR의 목표:** MCP Guide에 permission profile 안내와 영역별 tool·접근 레벨 표를 반영하고, 로컬 env·troubleshooting을 현재 CLI 동작에 맞춘다.

---

## 3. 주요 구현 내용 및 동작 방식

### A. MCP Guide 콘텐츠·화면 업데이트
- **관련 위치/대상:** `frontend/src/00_pages/mcp-guide/model/mcpGuideContent.ts`, `frontend/src/00_pages/mcp-guide/ui/McpGuideView.tsx`
- **변경 전 상황:** tool을 이름·설명 2열로만 나열. permission 섹션 없음. `publish_output` 중심 footnote.
- **변경한 내용:**
  - `read-only` / `safe-write` / `full` 프로필 표와 `openlog mcp permissions` 명령 안내 추가
  - tool을 영역(계정·workspace·task/log/todo/memory/output/link·삭제 등)별로 묶고 사용 가능 프로필 열 표시
  - `OPENLOG_MCP_CONFIG_FILE` 설명과 invalid permission config troubleshooting 추가
  - 기본 API origin footnote 및 발행 confirm/`skipConfirmation` 안내 갱신
- **변경 후 동작:** `/settings/mcp-guide`에서 최신 MCP permission·tool 범위를 EN/KO로 확인 가능. 런타임/API 동작 변경 없음.
- **영향 범위:** MCP Guide 페이지 UI·카피만
